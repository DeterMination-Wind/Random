# Random / 随机

> 给熟悉的 Mindustry 加一点可控的混沌感。

Random 会在不破坏逻辑的前提下打乱部分文字和主贴图，让熟悉的数据库、方块和单位获得完全不同的视觉体验。它适合想给下一局增加新鲜感、或单纯想看看传送带像炮塔会是什么样子的玩家。

这是一个纯客户端、可随时关闭的娱乐模组。变化只影响显示，离开世界后会恢复；正式游玩前请先在设置中确认是否启用了随机化。

## 使用

打开模组提供的随机化选项，然后进入世界即可体验。作为 Neon 组件运行时，功能会从 Neon 的统一入口启用。

## 构建

~~~powershell
.\gradlew.bat releaseBuild
~~~

## English

> Add a controlled dose of chaos to a familiar Mindustry.

Random shuffles selected text and main textures without breaking game logic, giving familiar databases, blocks, and units a different visual identity. It is for players who want a fresh, playful world or simply want to see a conveyor look like a turret.

This is a client-side entertainment mod that can be turned off. The changes affect presentation only and are restored after leaving the world; check the settings before using it in a serious play session.

## Usage

Enable the randomization options, then enter a world. When bundled in Neon, the feature is enabled from Neon's shared entry point.

## Build

~~~powershell
.\gradlew.bat releaseBuild
~~~
